# 文件说明

仓库里每个文件的作用。目录按"根目录 → db → docs → 源码 → 测试"排。

---

## 根目录

| 文件 | 作用 |
|---|---|
| `README.md` | 项目主页：功能、架构、快速开始、规则表、实测数据、局限 |
| `pom.xml` | Maven 配置：Java 17、JSqlParser、MySQL 驱动、Jackson、HikariCP、JUnit、shade 打包 |
| `LICENSE` | MIT 许可证 |
| `.gitignore` | 忽略 `target/`、`.idea/`、报告产物、本地配置等 |
| `docs/` | 设计、使用、文件说明、基线/对比数据、示例报告 |
| `db/` | 建库、建表、慢 SQL、优化索引脚本 |
| `src/` | Java 源码、资源、测试 |

---

## db

| 文件 | 作用 |
|---|---|
| `00_init.sql` | 建库 `slow_sql_lab`，建 `sqlquery`（读写 + DDL）和 `sqlquery_ro`（只读）账号 |
| `01_schema.sql` | 建 `t_user`、`t_order` 和初始索引；`create_time` 故意不建索引，`status` 低区分度 |
| `02_typical_slow_sql.sql` | 16 条典型慢 SQL，覆盖全表扫描、索引失效、回表、filesort、深分页、笛卡尔积等；一次只执行一条 |
| `03_optimized_indexes.sql` | 可选的优化索引，用来复现"优化后"效果；末尾带回滚语句 |

## src/main/java/com/sqlquery

### 入口与编排

| 文件 | 作用 |
|---|---|
| `Main.java` | 命令行入口：默认诊断 Q01，也支持传 SQL、`-v`、`bench`、`slowlog` |
| `service/DiagnosisService.java` | 一次诊断的编排：AST → EXPLAIN → 元数据 → 规则 → 建议 → 可选测量 |

### config / db

| 文件 | 作用 |
|---|---|
| `config/AppConfig.java` | 数据库配置，默认值面向本地实验库，可用环境变量覆盖 |
| `db/Db.java` | HikariCP 连接池的创建和关闭 |

### collect

| 文件 | 作用 |
|---|---|
| `collect/ExplainCollector.java` | 执行 `EXPLAIN FORMAT=JSON` + `SHOW WARNINGS`，只允许 SELECT |
| `collect/ExplainParser.java` | Jackson 递归解析 EXPLAIN JSON，处理 `nested_loop`、排序、分组 |
| `collect/SessionStats.java` | 读 `SHOW SESSION STATUS LIKE 'Handler_read%'`，算前后差值 |

### model

| 文件 | 作用 |
|---|---|
| `model/ExplainPlan.java` | 执行计划模型：query cost、filesort、temporary、tables、原始 JSON、改写 SQL |
| `model/TableAccess.java` | 单个 table 节点：表名、访问类型、索引、扫描行数、used_columns |
| `model/SqlFeatures.java` | AST 特征：表/别名、等值、范围、JOIN、排序、分组、函数、通配、LIMIT |
| `model/ColumnRef.java` | 带表名的列引用 |
| `model/TableRef.java` | 表名 + 别名 |
| `model/ColumnLiteral.java` | "列 vs 字面量"的比较，用于隐式转换判断 |
| `model/LiteralKind.java` | 字面量类型：字符串 / 数字 / 其他 |

### parse

| 文件 | 作用 |
|---|---|
| `parse/SqlAnalyzer.java` | JSqlParser 解析单条 SELECT，产出 `SqlFeatures` |
| `parse/UnsupportedSqlException.java` | 不支持的 SQL 形态（子查询、UNION、DML） |

### meta

| 文件 | 作用 |
|---|---|
| `meta/TableMetaLoader.java` | 从 `information_schema` 读表行数、列类型、索引、Cardinality |
| `meta/TableMeta.java` | 一张表的元数据 + 现有索引 + 选择性估算 |
| `meta/IndexMeta.java` | 单个索引：列顺序、是否唯一 |
| `meta/ColumnMeta.java` | 列类型、字符集，判断字符串列 |

### rule

| 文件 | 作用 |
|---|---|
| `rule/Rule.java` | 规则接口：id/title/severity/check |
| `rule/RuleEngine.java` | 遍历规则、去重、按严重度排序；单条规则异常不影响整体 |
| `rule/Issue.java` | 一条问题：规则、严重度、证据、建议、涉及列 |
| `rule/QueryContext.java` | 规则输入：SQL + 特征 + 执行计划 + 表元数据 |
| `rule/Severity.java` | HIGH / MEDIUM / LOW |
| `rule/rules/FullScanRule.java` | R01 全表扫描 |
| `rule/rules/IndexNotUsedRule.java` | R02 有可用索引但没选中 |
| `rule/rules/FunctionOnColumnRule.java` | R03 WHERE 列被函数包裹 |
| `rule/rules/ImplicitConversionRule.java` | R04 字符串列 vs 数字字面量 |
| `rule/rules/LeadingWildcardRule.java` | R05 `LIKE '%x'` |
| `rule/rules/OrConditionRule.java` | R06 OR 导致索引失效 |
| `rule/rules/BackToTableRule.java` | R07 回表 |
| `rule/rules/FilesortTemporaryRule.java` | R08 filesort / 临时表 |
| `rule/rules/DeepPaginationRule.java` | R09 深分页 |
| `rule/rules/CartesianJoinRule.java` | R10 隐式笛卡尔积 |

### advise / bench / report / slowlog / tools

| 文件 | 作用 |
|---|---|
| `advise/IndexAdvisor.java` | 生成索引建议：列序、覆盖、已有索引比对、风险提示 |
| `advise/IndexSuggestion.java` | 一条建议：表、列、是否覆盖、DDL、理由、风险 |
| `bench/Benchmark.java` | 预热 2 次 + 正式 3 次取中位数，记录 Handler |
| `bench/Measurement.java` | 测量结果：中位耗时、Handler、返回行数 |
| `report/AnalysisResult.java` | 一次诊断的完整结果，报告生成器的输入 |
| `report/ReportGenerator.java` | 生成 Markdown / HTML 报告 |
| `slowlog/SlowLogEntry.java` | 一条慢日志：时间、Query_time、Rows_examined、SQL |
| `slowlog/SlowLogParser.java` | 解析 MySQL FILE 格式慢日志 |
| `slowlog/SlowLogAggregator.java` | 归一化、指纹、按总耗时聚合 |
| `tools/SeedData.java` | 造数：10 万用户 + 100 万订单，80/20 倾斜 |
| `tools/BaselineRunner.java` | 批量跑 16 条 SQL，写 `docs/baseline.csv`；Q12 只 EXPLAIN |

### resources

| 文件 | 作用 |
|---|---|
| `src/main/resources/logback.xml` | 日志格式，避免 HikariCP 默认 DEBUG 刷屏 |

## 阅读顺序

1. `README.md`：先知道它做什么；
2. `docs/使用说明.md`：把它跑起来；
3. `docs/设计说明.md`：理解模块和取舍；
4. `Main.java` → `DiagnosisService.java` → 各 `collect/parse/rule/advise` 包；
5. 测试文件：看每个模块的输入输出。
